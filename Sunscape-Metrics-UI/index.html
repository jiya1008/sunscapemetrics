    About this prototype

    Methodology

    How Sunscape Metrics turns weather inputs into heat-risk status.

    Weather / forecast data→ Data processing→ Heat-risk engine→ Heat status→ Early warning→ Area comparison

    This prototype processes weather and forecast values, then assigns NORMAL, ELEVATED or HIGH using project-defined apparent-temperature and humidity thresholds. Status is interpretive, rule-based analysis — not a weather prediction engine.

    These are project-defined prototype thresholds and are not official government heatwave declarations. Sunscape Metrics does not claim to outperform existing weather services and does not provide medical guidance.

    Intended data sources

    • Open-Meteo for temperature, humidity and forecast fields
    • OpenStreetMap via Leaflet-compatible tiles for geographic context
    • Area definitions covering Mumbai, Navi Mumbai and Thane within MMR

    Demo values currently stand in for future /api/heatwatch, /api/heatalert and /api/heatmap responses.
